BRAND STRATEGIST PORTFOLIO

Files:
- index.html: the homepage
- style.css: all styling and responsive layout

Quick start:
1. Keep index.html and style.css in the same folder.
2. Open index.html in a browser to preview it.
3. To publish with GitHub Pages, upload both files to the repository root and enable Pages in repository Settings > Pages.

CUSTOMIZE BEFORE PUBLISHING:
- Replace Alex Morgan with your name.
- Replace hello@example.com with your email address.
- Replace sample experience, education, languages, and LinkedIn URL with your real details.
- This is plain HTML/CSS with a tiny inline script for the year and scroll reveals; no build step is required.
